# Kloova website

The public website for the Kloova iPhone app, served by GitHub Pages at https://getkloova.com.

- `index.html` — home page
- `privacy/index.html` — privacy policy
- `support/index.html` — support and FAQ (contact: help@getkloova.com)
- `404.html` — not-found page
- `CNAME` — custom domain for GitHub Pages (`getkloova.com`)

It is plain static HTML with inline CSS: no build step, no JavaScript, no external scripts.

The privacy policy's source copy lives in the private app repo, at `docs/privacy/index.html`. Edit it there first, then copy it over to `privacy/index.html` here (keeping the nav and the contact email).

Note: the repo is still called `closet-legal` from when it only held the Closet privacy policy. Once the custom domain is set, the old URL https://pchoww19.github.io/closet-legal/ redirects to https://getkloova.com/ (the home page), which links to the privacy policy.
